# Agent Share

A collection of agent configurations and setups for reference purposes.

## ⚠️ Important Notice

These configurations are **vibe coded** and should **not be directly copied** for use. They are shared as reference material for agents to understand patterns and adapt for their own specific needs.

## Purpose

This repository serves as a reference library for:
- Agent configuration patterns
- Setup examples
- Workflow inspirations

Use these as starting points to vibe your own configurations that fit your specific context and requirements.

## Skills library

`skills/` is the Honcho-backed library that the Amp `find-hot-skill` plugin searches. Each skill is `skills/<name>/SKILL.md`. Rebuild the index with `bun scripts/index-skills.ts` (GitHub Action `Index skills` on `main`).
